# 关于猫团团-TRPG

猫团团-TRPG（maott-TRPG）是一款面向玩家、主持人与剧本创作者的网页跑团工具。它希望把角色、背包、场景、战斗与消息放进连续流程，让一张桌上的人更容易跟进正在发生的事。

## 项目原则

- 真人GM主持，规则与剧情后果由明确权限确认。
- 开源自部署，使用者管理自己的环境与数据。
- 模型与外部渠道可选，不把AI接入变成开团前提。
- 对实际支持、人工裁定、规则与素材来源分别说明。
