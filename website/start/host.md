# 自部署第一次运行

> 目标：走完一条连续流程；AI与QQ默认不需要配置。

1. 确认[Node与包管理器](/deploy/requirements)符合要求。

2. [获取版本与安装](/deploy/install)，保留锁文件。

3. [构建并启动](/deploy/run)，检查本机页面与保存。

4. 按需配置[同网或公网访问](/deploy/network)；GitHub Pages仅托管本介绍站。

5. 了解[数据备份](/deploy/data)和[更新回退](/deploy/update)，再邀请真实团员。

## 你现在应看到什么

完成这条路径后，应能在自己的实际页面看到已保存状态、当前角色或服务结果。遇到问题先查[常见问题](/help/)，不要以重复提交代替确认。
