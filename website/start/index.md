# 选择你的上手路径

先走完一条路径，再逐步认识更多工具。你不需要同时学习部署、建卡、GM审核和模型配置。

## 我是玩家

[加入已有房间](/start/player)：使用GM提供的可用地址，获取角色控制，读完开场，采取第一次行动。

## 我是GM

[主持第一场冒险](/start/gm)：导入原创示例，邀请与分配角色，保存队伍并入场，审核一次行动。

## 我想写剧本

[制作可复用的小故事](/start/creator)：角色位、场景、NPC与事件，从最小主线开始。

## 我要自行部署

[运行自己的实例](/start/host)：安装、构建、启动，再按需设置账号与网络。
