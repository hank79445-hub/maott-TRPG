# 玩家第一次加入

> 目标：走完一条连续流程；AI与QQ默认不需要配置。

1. 从GM获取可用邀请并[加入房间](/guide/player/join)。

2. [获取角色控制](/guide/player/control)，请GM保存队伍并安排入场。

3. 阅读四段开场；可以自己翻页，暂关后从场景工具继续。

4. [查看角色与背包](/guide/player/character-sheet)，再[移动或互动](/guide/player/explore)。

5. 提交后等待必要的GM审核，看到确认结果再继续。

## 你现在应看到什么

完成这条路径后，应能在自己的实际页面看到已保存状态、当前角色或服务结果。遇到问题先查[常见问题](/help/)，不要以重复提交代替确认。
