# GM第一次开团

> 目标：走完一条连续流程；AI与QQ默认不需要配置。

1. 准备自己的可用实例；自行运行请先读[部署入门](/deploy/requirements)。

2. 在地图中导入[原创示例冒险](/examples/)，或从已配置账号的剧本库启动版本。

3. [邀请与分配角色](/guide/gm/members)，保存队伍并进入开始场景。

4. [配置并启动四段开场](/guide/gm/opening)。

5. 让玩家移动、访问容器并提交一次行动，在[审核入口](/guide/gm/review)确认后果。

## 你现在应看到什么

完成这条路径后，应能在自己的实际页面看到已保存状态、当前角色或服务结果。遇到问题先查[常见问题](/help/)，不要以重复提交代替确认。
