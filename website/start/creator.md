# 创作者第一次制作

> 目标：走完一条连续流程；AI与QQ默认不需要配置。

1. 先玩完[原创示例](/examples/)，识别一个可走通的流程。

2. [新建剧本](/guide/creator/new-script)，准备角色位和三处场景。

3. 设置[NPC、物品与遭遇](/guide/creator/actors)以及[事件触发](/guide/creator/story-flow)。

4. 配置角色位身份与开场，预检后[保存版本并导出](/guide/creator/versions)。

5. 在新实例试跑，确认模板没有带入上次库存与玩法状态。

## 你现在应看到什么

完成这条路径后，应能在自己的实际页面看到已保存状态、当前角色或服务结果。遇到问题先查[常见问题](/help/)，不要以重复提交代替确认。
