# 暮灯驿站的失物

一场原创教学冒险：雨夜中，驿站管事请你们找回准备随商队出发的补给。两位角色各有一点只有自己知道的来意；庭院、大厅和小地窖连接成一条可走通的练习路线。

## 你会练习什么

1. 让GM与两位玩家加入同一场冒险并分配角色。
2. 独立阅读四段开场和自己的身份。
3. 在地图移动，访问补给箱，领取、放入、关闭再打开。
4. 提交一次调查，由GM确认结果。
5. 在有资格的角色身上测试一份卷轴与其实际消耗。
6. 按需要进行一次可选战斗，结束后核对保存。

## 下载与导入

- [原创剧本ZIP](/downloads/lamplit-inn.trpg-script.zip)：在已配置账号的剧本库预览导入，再从版本开团。
- [本机冒险JSON](/downloads/lamplit-inn.trpg-map.json)：在地图模块使用导入入口，适合先练习纯Web基础房间。
- [作者格式JSON](/downloads/lamplit-inn.authoring.json)：供创作者阅读和修改。
- [预制角色包](/downloads/lamplit-inn-characters.zip)：两份SRD低等级教学角色。
- [校验清单](/downloads/SHA256SUMS.txt)：下载文件的SHA-256。

兼容：公共预览版0.57.0-public.2。规则依赖仅SRD5.2.1；无需配置模型或QQ。不要把冒险存档当成永久模板重复覆盖正在进行的真实房间。

## GM带团顺序

先在本机导入冒险并核对预制角色与三个场景，创建房间后邀请玩家。分配角色、保存队伍、入场后配置并播放开场。让一位玩家访问补给箱，另一位调查门边线索。可选战斗由GM确认后再开始，不强迫玩家跳过对话。

## 收尾与再次使用

确认调查结果、广播与库存，保存本次会话。再开一团时从剧本版本或原始冒险文件生成新实例，避免复用上一团已经取空的存档。
