# 更新与回退

> 适用：自行部署者 · 公共版 0.57.0-public.1 · 使用指南

让升级有可验证的返回路径。

## 开始前

准备自己的可写目录与终端。操作对象是自己的部署，不包含作者的运行环境或账号。

## 按步骤操作

### 01 · 记录当前提交与版本

记录当前提交与版本，正常关闭并备份需要保留的数据和原程序。

### 02 · 查看更新说明与兼容范围

查看更新说明与兼容范围，获取明确的新版本，在隔离目录安装和构建。

### 03 · 替换程序后检查健康、登录、静态页面与合成操作

替换程序后检查健康、登录、静态页面与合成操作，再确认原数据可用。

### 04 · 失败时按原版本与数据兼容性回退

失败时按原版本与数据兼容性回退，保留错误记录，不反复覆盖不确定状态。

## 命令示例

在项目根目录执行，终端成功后再继续。

```sh
git fetch --tags
# 在隔离目录检查目标发行标签，再安装、测试和构建
```

## 完成后检查

- 新版本在隔离目录完成安装、构建与合成启动检查。
- 旧版本程序和兼容数据备份仍可用于既定回退步骤。

## 边界与常见错误

更新程序、迁移数据与发布介绍站是不同动作，分别保留记录。

升级后空白时核对浏览器缓存和静态产物；数据问题先保护原备份。
