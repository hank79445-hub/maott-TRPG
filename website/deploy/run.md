# 构建、启动与正常关闭

> 适用：自行部署者 · 公共版 0.57.0-public.2 · 使用指南

用前台服务保持状态可见。

## 开始前

准备自己的可写目录与终端。操作对象是自己的部署，不包含作者的运行环境或账号。

## 按步骤操作

### 01 · 在项目根目录运行 pnpm build

在项目根目录运行 pnpm build，得到dist网页和.local/server服务端产物。

### 02 · 运行 pnpm start

运行 pnpm start，打开终端显示的本机地址。保持终端运行，初始实例仅监听本机。

### 03 · 使用完成后在终端按Ctrl+C正常关闭

使用完成后在终端按Ctrl+C正常关闭；重新启动后检查房间与保存结果。

## 命令示例

在项目根目录执行，终端成功后再继续。

```sh
pnpm build
pnpm start
```

## 完成后检查

- 浏览器可以打开终端给出的本机地址。
- Ctrl+C关闭后该测试实例退出，再次启动可读取自己保存的数据。

## 边界与常见错误

运行数据保存在自己的.local目录；首次运行会新建数据，不需要作者账号。

页面打不开时核对启动是否成功、端口是否占用以及实际访问地址。
