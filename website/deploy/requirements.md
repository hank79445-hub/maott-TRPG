# 环境要求

> 适用：自行部署者 · 公共版 0.57.0-public.2 · 使用指南

准备通用环境，避免依赖作者机器。

## 开始前

准备自己的可写目录与终端。操作对象是自己的部署，不包含作者的运行环境或账号。

## 按步骤操作

### 01 · 安装Node.js 24或更高的受支持版本

安装Node.js 24或更高的受支持版本，检查 node --version。使用本仓库固定的pnpm版本11.25.0。

### 02 · 准备Git或从发行源码包解压

准备Git或从发行源码包解压，使用可写目录，确保依赖下载与原生模块构建条件满足。

### 03 · 确认本机端口8787和开发页面端口5173可用

确认本机端口8787和开发页面端口5173可用；可选管理端口与公网配置另外检查。

## 命令示例

在项目根目录执行，终端成功后再继续。

```sh
node --version
npm install --global pnpm@11.25.0
pnpm --version
```

## 完成后检查

- node --version 满足Node 24或更高要求，pnpm --version 为11.25.0。
- 项目目录可写，所需端口可用。

## 边界与常见错误

首发在Windows环境完成验证。其他系统按Node与原生依赖要求安装，未验证平台不标为已全面支持。

版本不符时先升级环境；不要复制作者的node_modules到不同系统。
